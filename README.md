# kicad-inventree-build

Ties a KiCad PCB design to an InvenTree **Build Order**, so that physically
placing a component during assembly consumes its stock in InvenTree.

Two plugins, each living where its data does:

| Package | Runs in | Does |
|---------|---------|------|
| [`kicad-plugin/`](kicad-plugin/) | KiCad (Tools → External Plugins) | **Sync BOM to InvenTree** (match KiCad symbols to InvenTree parts, write the assembly BOM) and **Generate Build iBOM** (build-order-scoped InteractiveHtmlBom, uploaded to the Build Order) |
| [`inventree-plugin/`](inventree-plugin/) | InvenTree (Build Order page panel) | Embeds that iBOM full-screen; checking "Placed" calls InvenTree's real stock-consumption action |

The design rationale, decisions and phased build plan live in
[`docs/plan.md`](docs/plan.md).

## How it fits together

```
        KiCad design                          InvenTree
   ┌──────────────────┐                 ┌────────────────────┐
   │  schematic + PCB │                 │  parts, stock,     │
   │                  │ ─ Sync BOM ───► │  assembly BOM      │
   │                  │                 │        │           │
   │                  │                 │        ▼           │
   │                  │ ─ Gen iBOM ───► │   Build Order      │
   └──────────────────┘   (attachment)  │   + iBOM panel     │
                                        └────────────────────┘
                                                 │
                                     place a part in the panel
                                                 ▼
                                        stock consumed for real
```

The iBOM render itself is generated by, and stays 100% unmodified from,
[InteractiveHtmlBom](https://github.com/openscopeproject/InteractiveHtmlBom).
This project hooks it only through iBOM's own supported `user.js` extension
point — no fork, nothing to re-merge on iBOM updates.

## Requirements

- KiCad 9/10 (plugin runs under KiCad's bundled Python)
- InteractiveHtmlBom installed as a KiCad plugin
- InvenTree **1.3.x or newer** (the panel uses `UserInterfaceMixin`, and
  requires the `ENABLE_PLUGINS_INTERFACE` global setting)
- Optional: [`inventree-lcsc-import`](https://github.com/samturner3/inventree-scripts)
  — enables creating InvenTree parts from an LCSC part number for components
  that were never purchased. Everything else works without it.
